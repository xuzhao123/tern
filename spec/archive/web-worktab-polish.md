# 网页端工作面板标签：标题和关闭放进同一个标签

状态：已实现并验收（2026-10-31，用户要求 Claude Code 直接实现，分支 `web-sidebar-polish`）。不改标签的打开、关闭、恢复逻辑。

用户确认时要求把原来列为“这一期不做”的两点一起做：标签放不下时最左边露出半个；面板内容区自己的 × 和标签的 × 重复。见下面“放不下时”“内容区不再放关闭”两条。

## 为什么要改

右侧工作面板（`#workpanel`）顶上的每个标签由 `workpanel.js` 拼成 `div.work-tab` 里的两个按钮：标题（`role="tab"`）和关闭（`×`）。两个按钮都是 `button.ghost`（`workpanel.js` 的 `button()` 给的类名），`.ghost`（`app.css:562`）自带 1px 边框和 `--panel` 底色，`.work-tab button`（`app.css:442`、`layout.css:198`）只改了字号和内边距，没去掉边框与底色。结果在 1400×900 下截图：每个标签画成两个框，“计划”一个框、“×”另一个框，× 看起来像一个单独的标签，和它关的是哪个标签对不上。

## 改成什么样

一个标签就是一个框：`[文件图标 标题 ×]`。

- 两个按钮去掉边框和底色（`border:0; background:none`），底色、圆角只在外层 `.work-tab` 上：当前标签 `--panel` 底加轻阴影（现在 `layout.css:197` 的写法不变），其余透明，悬停 `--hover`。
- 标题按钮内边距 `6px 2px 6px 8px`，关闭按钮 18×18、圆角 4px，紧跟标题右边，标签右内边距 4px；关闭的图标用 `util.js` 已有的 `icon("close")`（线条画的 ×），12px，颜色 `--muted`，悬停时 `--text` 加底色。
- 关闭按钮只在当前标签、悬停或键盘聚焦这个标签时显示（`visibility`，不改宽度，标签不会因悬停变宽）；触屏（`@media (hover:none)`）一直显示。
- 放不下时：标签先收窄（`flex:0 1 auto`，最窄 104px，标题至少露出四个汉字），再横向滚动。滚动条隐藏，竖向滚轮换成左右滚；手动滚动按标签左边吸附（`scroll-snap`）。切换、新开标签后由 `revealTab` 定位置：当前标签完整露出，最左边从某个标签的左边开始；滚到头也对不齐时，末尾的 `.work-tabs-end` 补一段空白。
- 内容区不再放关闭：浏览器、后台命令、任务产物、网页预览、项目文件（两处）、持续 Goal、项目操作、交付修改这几个面板的标题行里原来都有“关闭”或 ×，调的都是 `closeWorkTab()`，和标签上的 × 是同一件事，全部去掉；刷新、查看差异等其他按钮留着。整个工作面板的关闭仍是标签栏最右边的 ×。

## 按文件的改动

| 文件 | 改动 |
| --- | --- |
| `internal/web/page/layout.css` | `.work-tab` 一段重写：按钮去边框与底色（含 `.ghost:hover` 的覆盖）；关闭按钮的尺寸、图标、显示规则；`.work-tab:hover` 底色；收窄、隐藏滚动条、吸附；`.work-tabs-end` |
| `internal/web/page/workpanel.js` | 关闭按钮换成 `icon("close")`，类名 `work-tab-close`；`revealTab` 取代原来的 `scrollIntoView`；`scrollTabs` 把竖向滚轮换成左右滚；标签末尾加 `.work-tabs-end`。`resourceIcon` 里的局部变量 `icon` 改名 `box`，免得遮住导入的 `icon` |
| `browser.js`、`jobs.js`、`files.js`、`preview.js`、`projectfiles.js`、`continuous.js`、`git-delivery.js`、`operations.js` | 去掉标题行里的关闭按钮和随之不用的 `closeWorkTab`、`icon` 导入 |

不要改：标签的顺序、键盘左右切换、关闭后“恢复标签”、标签宽度上限（190px）、右边的 ＋、⋯ 和关闭面板按钮。

## 这一期不做

- 标签的图标：除子智能体、浏览器、预览外都是同一个文件图标，不在这次分开。
- 子智能体详情里的“←”是返回列表，不是关闭，保留。
