# 网页端：Esc 打断、复制回答、导出对话

状态：设计（2026-10-24），交给 tern 实现（codex-parity-plan.md 3.8、3.9）。

## 1. 为什么要改

- **3.8**：停下正在跑的一轮只能去点停止按钮。Codex 按 Esc 打断；有待发送的插话时，Esc 是打断并马上把插话发出去。
- **3.9**：想把 tern 的回答贴到别处，只能用鼠标拖选，Markdown 格式也丢了；整条对话没法存成一个文件。观测页“原始输入 / 原始输出”卡片上的复制按钮（`internal/web/page/util.js:135` 的 `rawCard`）复制的是模型请求的原始 JSON，不是回答。Codex 有 `/copy`（复制最后的回答）和 `/export`（导出成 Markdown）。

## 2. 改什么

### 2.1 Esc 打断（3.8）

- 在对话页按 Esc，同时满足这几条才生效：
  - 当前对话在运行（停止按钮可见，`#send` 带 `stop`）；
  - 没有打开的对话框（`dialog[open]`）；
  - 斜杠菜单、`@` 菜单都没开；
  - 不在输入法组合输入中（`ev.isComposing`）。
- 待发送区（`#steer-strip`）里有插话时：和点“立即发送”一样（`sendSteersNow`）。没有时：和点停止一样（`stopRun`）。
- 第一次 Esc 已经在停止中（`r.stopRequested`）时再按：和再点一次停止一样，会弹“确定强制结束？”的确认。
- 运行中输入框的占位文字末尾补“ · Esc 打断”。

### 2.2 复制回答（3.9）

- 每一轮回答下面那一行（`chat.js:250` 的 `turn-sum`，“用时 … · 观测”）加一个“复制”链接：把这一轮最终回答的 Markdown 原文（`m.content`）写进剪贴板，成功时文字变“已复制”1.5 秒；剪贴板不可用（比如不是安全上下文）时变“复制不了，请手动选择”。

### 2.3 导出对话（3.9）

- 顶栏“沙箱文件”按钮旁边加“导出”（`#export-btn`），打开了一条有内容的对话时显示。
- 点了在页面里拼一份 Markdown 并下载，不经服务端：
  ```markdown
  # <对话名字，没有就第一句话>

  - 对话 ID：…
  - 主机：…；工作区：…；模型：…
  - 导出时间：…（本地时间）

  ## 第 1 轮

  **问：** <问题原文>

  （运行中补充：<插话原文>）

  **用到的工具：** bash × 3、edit_file × 2

  **答：**

  <回答 Markdown 原文>
  ```
  - 每一轮一节；撤销掉的轮次不导出；分叉带过来的轮次照常导出，标题后面注明“（分叉前）”。
  - 工具只列名字和次数，不导出参数和结果。
  - 没答完的轮次写“（这一轮没有回答）”。
- 文件名：名字或第一句话的前 30 个字，去掉文件名里不能用的字符，加 `.md`。
- 导入的对话、回放中也能导出。

## 3. 按文件的改动

| 文件 | 改动 |
| --- | --- |
| `internal/web/page/composer.js` | Esc 的处理（复用 `sendSteersNow`、`stopRun`） |
| `internal/web/page/shell.js` | 占位文字补“ · Esc 打断”；`#export-btn` 的显示 |
| `internal/web/page/chat.js` | 回答下面的“复制” |
| `internal/web/page/export.js`（新文件） | 拼 Markdown、下载 |
| `internal/web/page/index.html` | `#export-btn` |
| `README.md` | 网页端那段补一句：Esc 打断；回答下面能复制；顶栏“导出”把对话存成 Markdown |

不改：观测页的复制按钮、停止的流程、服务端。

## 4. 这一期不做

- 导出成 HTML、PDF。
- 导出工具调用的参数和结果。
- 复制一段回答里的某个代码块（代码块已有的复制按钮如有，不动）。

## 5. 验收

### tern 自己做（不需要真实模型，在沙箱里）

1. `node --check` 过改过和新加的页面脚本；`go build ./...` 通过。
2. 读代码报告：Esc 生效的几个条件；导出时跳过撤销掉的轮次的判断。

### Claude Code 在沙箱外做（真实模型、无头 Chrome，临时 `HOME`）

3. 让对话跑 `sleep 20`，按 Esc：这一轮停下。再跑一次，运行中插一句话再按 Esc：停下后插话作为下一条消息发出。
4. 打开撤销对话框时按 Esc：只关对话框，不打断。
5. 回答下面点“复制”：剪贴板里是回答的 Markdown 原文（用 CDP 授予剪贴板权限后读出来比对）。
6. 一条两轮、用过 bash 的对话点“导出”：下载的文件里有两节，问题、工具次数、回答都对；撤销掉第 2 轮后再导出，只剩一节。
