# 项目操作、初始化与持久开发服务

2026-10-28，EXT-05/WORK-06/19的沙箱服务依赖。当前明确支持Linux执行主机，其他平台返回能力不支持，不回退宿主无隔离命令。

- 项目配置 `.agents/actions.json`：`{"version":1,"actions":[{"name":"dev","command":"…","platforms":["linux"],"background":true,"ports":[3000],"initialize":false}]}`。最多30项，命令必须在显式预览后点击执行；读取配置不运行脚本。来源hash与目标目录一起用于启动校验。
- `workspace/operations/list|start|stop`，HTTP在当前任务路径下。start带动作名、配置版本、request_id和明确确认，后端从任务快照取真实目录/权限/网络白名单。相同实际目录和动作已有存活实例则拒绝重复启动，改变配置不能绕过实例检查。
- 独立的 `tern -shell` worker沿现有sandbox启动器运行，沙箱、资源限制、只读计划与网络白名单不变；标准输出实时写入有界私有日志。生命周期属于服务实例，独立于agent轮次和右栏标签。普通bash后台任务仍随原轮结束。
- 显式批准的port由服务网络namespace里的sandbox-init绑定私有Unix listener，仅转发到该namespace的固定loopback端口，不开放宿主TCP端口，不导出任意网络地址。后续preview只持具体实例与port的授权，不把端口号当全局权限。
- 服务记录和日志在专用运行目录持久化；app-server关闭/崩溃请求停止自有worker。重启不自动重新启动命令，旧记录显示已退出或状态待核对；PID及启动身份不匹配时不杀未知进程。确认旧worker已退出后才可显式重新运行。
- 初始化动作仅可在隔离副本任务中明确触发。失败保留副本和日志；重试提示可能已有部分副作用，不删除原项目或宣称脚本幂等。
- 日志不自动进入模型上下文；用户可明确加入当前已读日志片段。操作完成不等于整个任务完成。stop只作用于本系统所属实例，不按端口杀进程。

验收使用真实Git夹具、真实Python HTTP服务和真实沙箱：版本变更拒绝、重复启动拒绝、跨agent轮次保持、仅指定端口可达、停止/重启失效、plan权限下写入失败、初始化失败保留文件。
