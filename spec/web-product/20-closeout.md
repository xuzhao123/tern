# 开发收尾契约

2026-10-28。按用户要求由主 agent 单独实现和验收；覆盖状态仍记在 08，不以首版替代 B4 或后续候选。

## 查找与导航

- 操作面板提供操作、任务、项目文件、当前任务历史四类入口。跨任务搜索复用 `thread/search`，显示执行主机、项目与命中片段，部分主机失败明确显示，不把失败说成零结果。
- 新增只读 `thread/find`（HTTP `GET /runs/{id}/find`）：`query` 最长 200 字，`after` 为已扫描事件 seq，`through` 固定首次查询的历史边界。每页最多扫描 1000 条事件、返回 50 个命中事件；返回 `next`、`through`、`hits`。扫描可取消；翻页不混入新事件。范围为用户问题、最终回答、工具完成结果和人执行的命令输出，不搜索模型隐藏输入、认证或原始请求。
- 命中按原事件 seq/调用定位；已经加载的聊天可展开折叠的调用，缺失定位时保留可读片段，不能冒称已经定位。命中数表示已查询的命中事件数，不是全文出现次数。
- 文件快开复用当前任务实际目录的受限搜索，路径不跨任务或主机。恢复上一条输入仅在空输入、无补全、非 IME 时，由用户明确触发，恢复为草稿。

## 项目文件

沿用 `workspace/tree/list` 的逐目录、版本化分页及 `os.Root` 路径边界。高亮在本地 Worker 中运行，固定依赖版本，输出只通过文本节点和允许的 token class 渲染；失败回退原文。需真实验证中文输入、筛选、分页变化、窄屏及恶意 HTML 不执行。

## 设置与用量

设置按常规、模型、项目、权限、工具与集成、连接、高级、关于分类，继续使用原控件、设置来源和保存接口。`GET /version` 返回正在运行的 Web 版本/build 及各 app-server 最近一次握手的版本/build、连接状态；源码改动不等于进程升级，断线时版本只是最近握手结果。

上下文详情从实际模型请求的 usage 和运行实例报告的容量计算，未知容量不退回其他模型的默认值。累计用量包括主任务、子任务和辅助调用，并注明这不是账户额度/费用。手动压缩复用 `turn/start.compact`，用户选择后在下一条明确发送的消息前执行，准备期间可取消；草稿按任务保存这个选项，运行中禁止同时调度压缩，结果从真实 compact 请求展示。

## 显式 Skill 引用

选择器复用运行主机的技能解析器，引用包含 name/path/version。版本覆盖用途、来源及正文。发送时重新解析并检查当前启用状态、任务工具快照、路径和版本；不匹配拒绝且保留草稿。所选正文作为本轮 notes 的不可编辑快照提供给模型，start/continue 只记录引用元数据；这表示用户明确指定并加载了该版本，不声称模型已正确执行。权限不变。运行中选择保留在草稿中，等本轮结束后正常发送，不悄悄丢入只支持文字的插话/队列。

当前技能发现沿既有内置/执行主机个人目录规则；没有项目目录 Skill 覆盖能力，不伪标为项目来源。

## 子任务直接干预

新增 `thread/subagent/control`，目标必须为当前父轮记录中的 task_id + spawn call_id，agent 再核对真实存活子进程连接。支持 send/stop/status；send 使用 managed client_id，消费回执仍来自子任务的检查点/协议，不把传输成功写成已采纳。stop 只发送一次中断请求，不强杀、不影响兄弟任务；界面等真实 completed 才显示结束。写操作先审计并使用 request_id 持久认领，超时返回 unknown，不自动重放。主任务已结束后只能查回执或把建议恢复到主输入，让主任务按原 task_id 续跑；不重写任务另派一份。

## 产物预览与批注

项目文件和临时产物复用 `artifact-preview.js`：Markdown 渲染/源码、HTML 静态隔离预览/源码、图片缩放、PDF.js 本地固定版本逐页画布/缩放。HTML iframe 不开放脚本或同源权限；外部资源不自动加载，动态站点使用独立网页预览能力。项目全文上限仍为2MiB，临时产物预览上限10MiB；超限、加密/损坏PDF、编码不支持给真实原因和下载路径。

批注包含账号/主机/任务/来源类型/路径、读取内容hash、时间和行/页/归一化区域。使用独立ID的追加记录保存意见和删除事件，并行编辑保留各版本；未保存文字留独立草稿。加入输入前重新读版本，过期保留原定位和片段，并明确需重新核对。只形成输入草稿，未明确发送不调用模型。标签只持久化页面/缩放/模式等阅读偏好，不存认证或文件全文。
