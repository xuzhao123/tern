## 用户截图补充的具体结构

1. 主对话：侧栏浅灰，正文白底；侧栏顶部右侧是活动和搜索图标，下面是“新聊天”。任务行有小图标和状态点，操作按需出现。对话内容居中且两侧留白，用户消息为淡蓝色圆角气泡。工具过程使用灰色短行，不扩成连续卡片。
2. 输入区：与正文对齐的宽圆角输入框；左下角是添加和权限，模型/推理选择与发送或停止在右下角，用量圆环靠近模型。改动摘要位于输入框正上方，目标条贴在输入框上沿。目标条只能展示真实已保存目标；tern 当前的普通目标字段不冒充 Codex 的持续运行/暂停/预算状态，也不画不可用的暂停或计时按钮。
3. 子智能体：工作区标签下按“已开启 · N”“完成 · N”分组，采用平面列表。每行左侧独立颜色的身份图标，中间名称与灰色最新进度，时间靠右；点击进入详情。失败、中断与等待输入必须维持真实状态，不归入成功完成组。
4. 文件工作区：顶部统一资源标签栏；内容工具行左侧是可读的路径面包屑，显示更改及文件导航等动作在右侧；源码有行号和语法层次，右侧文件树带筛选。当前的项目文件预览与 diff 仍复用服务端受限读取，不能为外观扩大文件访问边界。目录树/语法高亮尚无完成证据时明确保留为待办。
5. 图像经过截图/缩放，无法据此断言原生 CSS 像素。先按比例调整：桌面侧栏约占主对话截图宽度的23%，正文和输入框同宽；将完整页面在同一视口核对。截图以浅色为主，深色和窄屏继续做适配，不声称已获得它们的原版视觉基准。
6. 用户再次明确：子智能体、查看文件、diff、打开网页均属于同一个**右侧工作区**。桌面默认保留左侧主对话，通过右栏顶部标签切换资源；子智能体总览及详情也在右栏，不能跳成独立主页面。最大化仅由明确操作触发；真正窄屏可从右侧覆盖展开并提供返回聊天，普通桌面宽度不能自动盖满对话。

## 必须修正的方向

1. 左侧保持窄而平静的任务/项目导航：单行标题、轻量选中态、状态点、按需出现的操作；不常驻显示“新任务/改名/移除”三连按钮和项目技术信息。
2. 顶栏以任务标题与少量图标操作为主。导出、旁支、观测、主机详情和执行路径收进菜单/详情，不能把所有现有能力横向排成工具按钮墙。
3. 对话正文保持稳定阅读宽度、字号和留白；agent 正文不套重卡片，工具过程收敛为可展开摘要。子任务摘要表达分工和状态，身份串与实现信息只在详情出现。
4. 输入区为连续工作的主操作点：文字区、附件/引用、模型/模式和发送/停止紧凑排列。默认不堆积禁用选择器、技术说明和持久状态段落；需要处理的异常才展开。
5. 右侧工作区以资源标签和当前内容为主，关闭、布局、宽度调整使用紧凑图标/分隔条/菜单；去掉常驻“打开/面板全宽/关闭其他/恢复标签/宽度滑块”工具墙。
6. 字体、灰度、边框、圆角、间距和图标统一。以明暗主题的整页效果判断，不能仅改变背景色宣称完成。
7. 保留已完成的草稿、恢复、状态和权限能力，界面重排不改变执行含义。尚未实现的 Codex 操作不得用空按钮冒充。

## 已落地的页面结构

- `layout.js` / `layout.css` 与 `index.html`：统一浅色/深色的中性灰、紧凑线条图标和留白。桌面侧栏按视口在248–300px间调整，顶部活动/搜索为图标，下方新聊天；任务行增加对话图标、项目行增加目录图标。项目操作收进行内菜单，筛选与全文搜索保留在“任务”菜单，筛选有效时明确显示“已筛选”。“搜索任务”直接进入任务模式，快捷键仍可调用操作面板。
- 顶栏保留标题菜单、“打开”、改动/工作区图标和必要状态。执行目录、目标、导出、旁支、副本应用、观测保留在标题菜单；复制任务 ID 的结果显示到菜单里，不因自动收起丢失回执。
- 正文和输入框同宽，用户消息浅色为淡蓝色气泡。附件/权限在输入框左下，用量圆环/模型菜单/发送停止在右下；模型菜单同时显示当前推理强度。已有任务展示它真实记录的模型，不能换成当前默认值。未记录则说明未记录，导入对话保留来源及其记录模型。主机、项目/副本位置放在输入框下面，观测页仍可切换主机。上方的改动摘要可重新读取工作目录；已保存目标在输入框上沿出现。
- `workpanel.js`：资源类型图标、标签与 `+ / ⋯ / ×` 同栏，管理操作收进菜单；宽度改用可拖动、支持方向键的分隔线。760px以上默认右栏与聊天并排，以下覆盖展开；明确选择全宽才隐藏聊天。选择、全宽、恢复、关闭后的焦点有明确去处，后台更新不抢当前输入；刷新仍恢复标签和阅读位置。
- `agents.js` / `agents.css`：独立右栏总览以已开启/完成/已结束/状态待确认分组；身份图标按稳定task_id保持颜色，状态和时间来自真实事件。点击进入详情，可返回总览；不把取回存档的时间当成原完成时间。主聊天中的子智能体条目也显示明确状态。
- `projectfiles.js`：文件上方显示项目内路径面包屑和“显示更改”；该按钮明确回到工作目录比较。源码行号为简洁行号栏，行选择/引用仍可用。目录、大小、时间、读取版本移入文件信息菜单；读取失败、二进制、过大等重要状态仍在内容区显示，不能藏进菜单。完整右侧文件树和语法高亮仍待实现。
- 所有菜单的 Escape 先关闭菜单；不应继续冒泡成停止任务。窄屏侧栏和标题菜单需单独验证，不能用桌面 CSS 检查代替。

上述属于实现状态。完整视觉与操作验收需要实际页面、明暗主题、窄屏以及运行/等待场景的证据；不能据此声称与 Codex 像素一致或全部功能完成。
