# 工作面板：资源标签、阅读状态与恢复

状态：开发中。对应 WORK-01/05/08、SUB-04、EXT-08，验收 A16/A17/A29/A39。完整文件读取、diff 范围与行反馈仍须按各自需求验收，本批不以面板外壳代替这些能力。

## 用户行为

- 对话右侧只有一个工作面板。改动、任务产物、命令、浏览器过程、子任务均从现有入口打开为资源标签；同一任务同一资源再次打开聚焦原标签。多文件、不同子任务与不同浏览器步骤可以各占一个标签。
- 标签切换保留滚动、文件展开、当前选中项及已有界面草稿。新工具事件只更新对应内容，不自动切换用户正在阅读的资源。选中文本时不因流式重绘打断选择。
- 提供隐藏面板、关闭当前标签、关闭其他标签、恢复最近关闭标签，以及分屏/工作面板全宽。关闭或恢复标签均不启动、停止或重复执行工具。
- 布局、打开资源描述和阅读位置按登录账号、主机、任务隔离保存在本浏览器。刷新重新从服务端读取资源，不能将认证令牌、文件正文、动态浏览器句柄写入 URL 或本地偏好。存储失败提示但不清空当前标签。
- 浏览器过程仍明确是现有工具的画面与文本，不能冒充 EXT-06 的用户可操作网页。任务产物保留现有上传/下载/删除权限；项目文件只读读取另补协议。
- 窄屏使用单个工作视图并提供回到对话；键盘可切换标签，关闭后焦点落在相邻标签或返回工作入口。跨任务导航保存当前视图，新任务不带入旧资源。

## 实现边界

新增 `page/workpanel.js` 持有界面标签描述与各实例的临时展示状态；`index.html` 增加外层工作面板，原 `subpanel` 成为内容容器。diff/files/jobs/browser/agents 的数据读取继续沿现有 HTTP 与任务事件，不复制执行状态。入口、关闭动作与任务切换统一接入标签管理。

第一批只增加前端偏好，IDL Diff：无。偏好版本独立于任务事件；仅恢复允许的资源类型和字符串标识。文件实例的异步读取只写回自己的状态，过时响应不能覆盖当前另一文件。后台命令日志轮询可随视图隐藏暂停，命令进程不变。恢复失效资源显示原因，可关闭，不静默改成另一个资源。

## 验收

在隔离真实任务中打开改动、两份文件、两个子任务/浏览器步骤，切换后检查内容、阅读位置与对话草稿；重复打开不重复建标签；关闭其他、恢复、隐藏/全宽切换、刷新和切任务回访均无工具重跑。文件变更/删除与读取失败显示真实结果。检查键盘导航、明暗主题、窄屏、流式输出不抢焦点以及账号/主机隔离。
