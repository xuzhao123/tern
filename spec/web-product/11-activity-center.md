# 活动中心与账号隔离的未读

状态：开发中。对应 EXT-02、CHAT-04、SUB-06；完整通过条件为 A32、A10、A25，不以本批局部验证关闭全部需求。

## 交付契约

- 侧栏“活动”打开独立面板，按主机、项目、待处理/运行中/完成未读/全部筛选。同一任务只出现一行，状态可重叠；归档任务的待处理仍可发现。失败的主机保留本页最后一次快照并标过期，不推断结束。
- 服务端继续拥有执行和等待状态。摘要兼容增加 `activity_seq`、`completion_seq`、`waiting_requests`；请求条目含稳定的事件标识、类型、调用/子任务/域名定位信息，不复制工具参数或凭据。保留旧 `waiting` 字段。
- 待处理详情复用原审批和提问控件、权限与服务端原子处理；入口可直达某个请求，来源未知时明确未知，不凭任务名称猜来源。请求已结束时不能继续显示可批准。
- 阅读游标按账号、主机、任务保存在本浏览器，版本由活动时间和事件序号组成；手动标未读是独立标记。自动可见阅读不清除手动未读，主动打开/显式标已读才清除。活动面板遮住对话时不自动标当前任务已读。
- 批量已读固定点击时筛选出的任务及版本，只确认这些版本。期间新增活动仍未读；阅读操作不批准或清除待处理。浏览器多页变更相互刷新，存储失败明确提示。
- 原 `tern-seen` 未带账号，不能可靠归属，不自动迁移。新账号首次打开的历史可能未读；旧数据不删除。通知偏好也按账号保存，默认关闭。
- 通知分本轮完成、审批、提问，各有关闭/仅后台/始终。Web Locks 串行认领通知，localStorage 保存每任务每类型已认领事件标识；原生 tag 作为额外合并。无锁或存储失败时暂停系统通知并说明，页面活动仍可见。不保证页面关闭后通知。
- 仅新观察到的状态变化产生通知；初次读取或失联后的首次恢复不补发历史通知。点击通知定位任务和请求；手动已读不影响审批。

## 落点与兼容

`appserver/server.go` 增量摘要；`page/activity.js` 聚合视图、定位和通知；`util.js` 本地阅读游标；`shell.js` 复用任务列表快照；`connection.js` 连接失效；`pages.js` 分类通知；`index.html`/`app.css` 面板。协议版本不变，旧客户端忽略新增字段；旧服务仅能显示任务级等待，不伪造请求定位。

## 验证

Go 格式/vet/build、全部 JS 语法；隔离服务真实模型发起提问，活动列表显示运行与等待并可回答；两页标未读/已读互相同步；账号切换隔离；批量已读后新轮次仍未读；刷新保留；断线标过期。系统通知权限与实际桌面投递单独验证，未验证不宣称通过。
