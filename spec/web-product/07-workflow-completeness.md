## 2. EXT-01：命令面板与快速导航

统一面板提供“操作 / 任务 / 文件”分类和可键盘搜索的入口，始终显示当前项目与主机。操作示例：新任务、打开改动、进入设置、切换任务、定位待处理项。菜单只出现当前可用操作；不可用项可以解释原因，不执行隐藏的默认替代。

- **当前任务内查找**与跨任务搜索分开：显示命中数、上一处/下一处，点击定位到消息或已授权可读的工具输出；折叠内容命中时能展开。大历史使用可取消、可分页的查询，不以浏览器 Ctrl+F 只搜已挂载 DOM 冒充全历史查找。
- **文件快开**只检索当前任务实际工作目录，在副本中打开副本文件；同名结果显示路径，跨主机不能混用。
- **恢复上一条输入**仅在输入框为空且补全关闭、非 IME 组合态时提供；恢复成草稿，不立即发送。不覆盖用户已有文字，历史按账号与任务隔离。
- 命令面板关闭后焦点回原控件；键盘提示与设置页来自同一份操作定义。浏览器保留键无法可靠拦截时提供按钮和替代组合，不照搬桌面快捷键。
- 所有会改数据的操作仍经过原有预览/确认与权限流程，搜索命中本身不执行。

## 3. EXT-02：活动中心

```text
活动       [全部主机 ▾] [全部项目 ▾]
[待处理 2] [运行中 3] [完成未读 4] [全部]

! 登录流程修复   dev / tern    等你批准命令      [处理]
● 接口检查       dev / api     子任务仍在运行    [查看]
✓ 页面布局调整   dev / web     本轮已结束        [查看结果]
                                              [全部标为已读]
```

状态是可重叠的筛选条件：运行中的任务也可能等待用户、存在未读内容；不能为了分类把真实状态丢掉。同一任务一行，子任务的等待事项显示数量并可展开来源，复用 SUB-06。

- 待处理入口成为活动中心的快捷筛选，不再维护第二份状态列表。
- 提供单任务“标为未读”、当前筛选结果“全部标为已读”；后者冻结点击时的目标集合与版本，操作期间产生的新消息仍未读。
- 阅读游标与“手动标未读”分开存储；标为已读不等于批准请求，也不清除待处理状态。
- 首版未读继续按账号、本浏览器隔离；活动执行状态来自服务端。来源断开显示状态可能过期，不显示“全部结束”。
- 通知分别配置本轮完成、权限审批、用户提问；支持关闭、仅页面在后台、始终（受浏览器许可限制）。同一事件跨页面去重，点击定位到实际任务/请求。
- 页面关闭后能否收到通知取决于独立后台通知能力；未实现时明确不保证，不用页面内 Notification 冒充离线推送。

## 4. EXT-03：上下文与用量

点击输入区用量指示进入面板：当前实际模型、上下文容量与占用、最近更新时间、压缩状态，以及可获取的本轮/任务用量。上下文占用、累计 token、账户额度、费用是不同指标，分开标单位和口径。

- 模型未报告容量/额度时显示“未知/供应商未提供”，不套其他模型默认值冒充精确数据。
- 费用只有在费率、输入/输出/缓存口径可核验时展示；估算必须标注，不承诺跨供应商费用统计已实现。
- 手动压缩有“准备中 → 压缩中 → 完成/失败”状态；运行中不能同时改写上下文，建议在安全轮次边界执行，用户可取消尚未开始的请求。
- 压缩成功才切换有效上下文；失败保留原上下文与草稿。用户可知道发生过压缩、压缩覆盖到哪里，但原始历史仍可查看。
- 达到配置预算/额度或模型限制时说明原因，保留草稿，提供调整配置或新开任务等实际可用路径，不悄悄换模型或扩大预算。
- 这与 Goal 预算协调：普通压缩不重置 Goal 的累计消耗。

## 5. EXT-04：显式 Skill 调用

在输入区的添加菜单或 `$` 触发的选择器中搜索 Skills，也可通过统一命令面板进入。与 `@` 文件、`/` 命令分开标识，复用现有 Skills 中心与权限设置。

选择项显示名称、用途、来源层级（内置/个人/项目）、所属执行主机与是否可用。选中后成为可移除的 Skill 引用，不立即执行，也不把整份正文直接塞进可编辑文本。

发送时服务端在当前项目/主机重新解析 Skill，记录身份与版本或内容摘要；同名覆盖按现有规则处理。已删除、禁用、不允许使用或来源变化时明确提示，不能静默选另一份同名 Skill。用户选择不能提升工具权限。

消息历史区分“用户指定了 Skill”和“agent 实际加载/使用了 Skill”。无法执行时显示原因；仅启用或选择过不算成功使用。运行中新增引用沿当前补充/排队规则提交，不假装改变已固定的本轮工具集合；需要新轮次时明确说明。

## 6. EXT-05：项目常用操作与初始化

项目菜单或顶栏提供“运行操作”，列出配置的启动服务、测试、构建等动作。每项包含名称、命令、所属目录/主机、平台条件、是否长期运行和停止方式。执行前能查看命令；动作不通过模型重新解释和改写。

- 操作运行沿用受控执行与权限机制，用户点击不能借配置绕开沙箱。项目配置里的命令作为待执行配置处理，不能因为打开项目就自动执行。
- 长期服务显示启动中/运行中/退出、日志与停止入口；重复启动检查已有实例，端口占用给出原因，不能自动杀掉未知进程。
- 操作的日志进入命令面板，明确与 agent 命令的关系；是否把输出加入模型上下文由用户选择或既定任务规则决定。
- “初始化隔离副本”与“常用操作”分开：首次运行前展示脚本、目录和授权；配置发生变化后重新确认适用范围。按当前 clone 副本落地，不依赖尚未实现的真 worktree。
- 初始化失败保留副本与日志，用户选择重试或移除自有临时副本；不能执行删除原目录的补偿动作。重试前说明脚本可能已有部分副作用，不承诺任意脚本幂等。
- 初始化结果是环境就绪状态，不能误报为用户任务已完成。不同平台不支持的命令禁用并说明。

## 7. EXT-06：网页预览与可视化反馈

核心流程：**启动/连接开发服务 → 在工作标签打开页面 → 点选元素或框选区域 → 写意见 → 加入输入 → agent 修改 → 刷新复验**。既能由用户输入 URL，也能从回答中的链接打开。

```text
预览：登录页   [dev · 端口映射信息] [刷新] [批注]
┌─────────────────────────────────────────────┐
│ 渲染后的页面                                 │
│                  ┌─────────────┐            │
│                  │ 选中的按钮  │  ①         │
│                  └─────────────┘            │
└─────────────────────────────────────────────┘
① 这个按钮在窄屏溢出了，请保持它在表单内部。
[删除] [修改意见]                    [加入输入]
```

每条反馈保存 URL、目标主机、捕获时间、视口尺寸、定位信息（可用时）、区域截图或图像引用、意见原文。选取目标时不触发目标按钮的业务动作；DOM 不可访问时允许区域批注，不伪造元素选择器。

- 点击“加入输入”只形成草稿，用户发送才执行；输入可增删批注，运行中沿现有补充/队列规则处理。
- 页面导航、重载、布局变化后，旧批注保留原快照并标版本/定位可能过期，不把旧坐标套到新页面。
- 支持人操作与 agent 操作之间明确的控制权切换；用户接管时 agent 不继续点击同一页面。具体浏览器控制通道需在实现 spec 中确定，不能用截图播放器冒充可交互预览。
- VM 的 localhost 不等于浏览器所在 Mac 的 localhost。打开前解析执行主机与可达端口；需要隧道时明确目标、端口与生命周期。服务不存在/连接失败保留原地址和重试入口，不擅自公网发布。
- 不依靠任意 URL 代理绕过 CORS、frame 限制、认证或站点安全策略；不能嵌入的页面说明限制并提供外部打开/受支持浏览器路径。选型失败属于明确阻塞，不能宣布预览闭环完成。
- 页面、DOM 与批注截图属于任务上下文，内容不当作系统指令；截图/页面内容提交前可预览和移除。登录交给用户完成，凭据不进入聊天文本。

首版要求至少在受支持的本地开发站点上验证完整反馈闭环。任意第三方站点、跨域登录态导入和通用远程浏览器平台不作为附带承诺。

## 8. EXT-07：产物预览与批注

文件列表与回答链接打开同一份资源实例。Markdown 支持渲染/源码切换，HTML 支持受隔离的预览/源码，图片支持缩放与区域批注，PDF 支持翻页、缩放和页内区域批注；不可用的预览器显示下载入口，不谎称格式已支持。

预览显示来源主机、路径、文件版本/修改时间。只读预览与编辑区别清楚，本期不把代码编辑器和 Office 编辑器一并实现。现有可视化代码块继续保留，不把代码块渲染等同任意 HTML 文件预览。

- 批注定位包含文件版本、段落/行或页码/区域、意见；用户发送后才进入模型上下文。文件更新后旧批注显示过期或需要重新定位。
- 渲染失败、超大文件、加密 PDF、损坏文件、编码不支持都要给真实原因；保留源码/下载路径，不能显示空白并当作成功。
- HTML/Markdown 不执行宿主页面权限下的脚本；预览资源、外链、下载沿受限路径处理。新增预览器不得撤销现有 sandbox iframe 与路径权限边界。
- 自动预览可以提示新产物，但不抢走用户正在查看的标签；对话完成时有可点击的产物清单。
- Office 文件先提供下载与明确限制，后续单独评估转换/预览，不计入本次四种格式承诺。

## 9. EXT-08：多标签与布局

WORK-01 的“改动/文件/命令/浏览器/子任务”是功能分类；这里补的是**同一类别内的多个资源实例**，例如同时打开两个代码文件和一个网页。两者统一在一个工作面板，不建立两套互相不知情的打开状态。

- 标签身份包含主机、任务、资源类型、资源标识与必要比较范围；同一实例重复打开聚焦原标签，不同主机同路径不合并。
- 切标签保留各自滚动、选中行、缩放、查找、批注草稿。支持关闭、关闭其他、重开最近关闭的标签，关闭不删除文件或停止命令。
- 支持对话为主、左右分屏、工作面板全宽；返回对话保留输入与阅读位置。窄屏维持单列切换。
- 刷新可恢复资源描述与布局，访问时重新校验权限和资源是否存在；不将临时浏览器句柄、认证令牌或文件正文塞入 URL。
- 命令会话、浏览器控制与标签生命周期分离，关闭前对正在执行或未保存的内容给出准确说明；不能因为恢复一个标签就重新启动服务或发送批注。
- 仅导航状态可恢复，不承诺浏览器已销毁后能恢复其登录态或动态应用状态。

## 10. EXT-09：Goal 持续任务模式

这是一种执行模式，和现有“目标文字提醒”、CHAT-07 的“计划清单”分别呈现。普通任务不会因写了一句目标自动进入持续执行；用户显式启动 Goal 后才由调度器持续推进。

启动前明确目标、约束、可核验的完成标准及停止条件。预算可选：用户设置的 token/时间/轮次上限必须执行；未设置时显示未设置，不宣称无限运行，并保留防止空转的系统约束。

状态至少包括：运行中、暂停中、已暂停、等待用户、受阻、预算耗尽、已完成、已结束（未完成）。界面展示当前进展、下一步、停止原因和累计消耗（来源可用时）。

| 操作/事件 | 行为契约 |
| --- | --- |
| 一轮结束但目标未完成 | 调度器依据当前状态决定是否继续；同一目标只允许一个调度所有者，不能每个网页各续发 |
| 暂停 | 立即禁止后续轮次，说明当前操作正在安全收尾或中断；实际停妥后才显示已暂停 |
| 恢复 | 重新检查主机、权限、目录与有效执行状态；接着当前目标，不重复已完成副作用 |
| 修改目标 | 保存版本并记录变更，明确当前操作是否已在执行；下一次决策按新版本，旧完成判定不能完成新目标 |
| 等待用户/受阻 | 显示具体原因与可解除条件；等待期间不空转消耗，不把服务不可用当成完成 |
| 达到预算 | 停止自动续轮，说明已完成和剩余部分；扩预算需用户显式操作，不自动重置消耗 |
| 宣布完成 | 对照完成标准列出证据和未覆盖项；缺关键证据不能仅凭模型说“完成”通过 |
| 结束/清除 Goal | 停止调度、保留历史和结果，明确是未完成结束还是已完成；不删除任务/文件 |
| 进程重启或响应未知 | 恢复持久状态并先检查当前轮/操作，不能把已运行请求重新派发 |

“停止当前轮”在 Goal 下同时暂停自动续轮，防止刚点停止又自动启动。已有排队消息与 Goal 续轮由同一调度入口串行仲裁：先处理用户已确认的输入，再决定目标下一步；不让两条路径各启动一轮。

子 agent 仍沿 SUB 专项约定跟随父轮生命周期；Goal 延长任务不自动延长某个子进程。进入下一轮时按稳定身份回收/续跑所需子任务，不能重复派发同一件事。关闭网页不等于暂停，服务仍运行时按既定模式继续，界面必须提前说明。

Goal 不提升权限、不自动批准、不自动提交/推送，不等于定时任务。手动暂停后重启不能自动恢复；被阻塞或预算耗尽后须满足条件才继续。

## 11. 实现落点与新增契约

本次只新增产品文档，**IDL Diff：无**。实现前按各包 AGENTS 细化接口；下面是责任边界，不是现存 API 名称。

| 范围 | 现有复用 | 新增设计必须明确 |
| --- | --- | --- |
| 操作与导航 | shell/composer/follow、任务搜索与 workspace/files | 统一操作定义；当前任务查找范围/分页；输入历史与账号隔离 |
| 活动 | runs/shell/util、列表与通知事件 | 阅读游标、手动未读、批量目标快照、通知去重 |
| 上下文/Skill | chat/composer/pages、模型用量、现有加载机制 | 压缩请求串行化与成功切换；可获取指标；Skill 解析来源与快照，不突破工具权限 |
| 项目操作 | app-server、现有沙箱命令与副本 | 配置版本、可信执行授权、实例身份、日志/停止、初始化失败和重试边界 |
| 网页反馈 | browser.js、现有浏览器能力 | 预览控制通道与 VM 可达性、控制权、定位/截图引用、站点权限与失败降级 |
| 产物与标签 | files/md/agents、受限文件 API | 版本化资源、预览器能力、批注引用、标签状态、过期/越权校验 |
| Goal | thread goal/turn/queue、agent 检查点与进程接管 | 持久状态与版本、单调度所有者、预算计量、队列仲裁、停止/恢复、完成证据；不能靠前端定时器实现 |

新增持久状态采用兼容字段/记录，不改写原始历史。旧客户端/旧后端不支持时不显示可执行按钮；关键能力不满足时按原任务模式运行并明确说明，不悄悄把 Goal 降级成一条普通消息。

以下定义 A31–A42 的完整通过标准；局部执行证据与未覆盖项见 [实现记录](08-implementation.md)。沿用 [总交付规则](04-delivery.md)，依赖真实模型、服务、浏览器的场景必须真实验证。

| --- | --- | --- |
| A31 / B1–B3 | 命令面板、当前任务长历史查找、文件快开、恢复旧输入；IME 和快捷键冲突 | 查找范围明确、命中能定位；主机/目录正确；不覆盖草稿、不误执行，焦点可返回 |

| A33 / B4 | 手动压缩与执行竞争、压缩失败、额度未知、预算达到上限 | 不并发破坏上下文；失败保留历史/输入；未知不伪造；不自动扩预算或改模型 |
| A34 / B2 | 显式选 Skill，同名覆盖、切项目/主机、禁用/删除、运行中补充 | 引用解析正确、不可用如实提示；选中不等于执行；实际使用可追溯，权限不扩大 |
