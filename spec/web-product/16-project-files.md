# 项目文件：只读预览、回答链接与行引用

状态：开发中。对应 WORK-05、CTX-03、EXT-01 文件快开，验收 A16/A17/A31；本文件不代替 WORK-02/03 的 diff 范围与行反馈。

## 产品行为

工作面板增加“项目文件”。按任务快照的实际工作目录搜索并打开文件，副本任务读取副本。搜索复用已有 workspace/files（每次至多 20 条，界面明确限制），输入完整路径也可直接打开。文件与任务产物分开，任务产物不再一律宣称位于 /workspace。

回答里的 Markdown 文件链接可打开文件标签并定位 `:行号` 或 `#L行号`。链接的上下文为当前任务及主机，只有服务端确认位于任务工作目录内才能读取；不能把 Mac 路径或别的主机的路径按同名文件自动替换。不存在、越界、目录、管道、非 UTF-8 和超大文件各显示真实原因。内容只作为文本显示，HTML 文件不得在宿主页面执行。

预览带实际目录、相对路径、内容版本、修改时间和行号，分段显示以避免长文件卡死；可跳到指定行。选择某行后“加入输入引用”只追加草稿，包含主机、任务、路径、行号、内容版本与原文片段，用户发送才进入上下文。引用表示阅读时快照，后续编辑仍须重新读文件，不把旧行号当当前事实。

## 协议与责任

- 新增 `workspace/file/read {threadId, path}`，web `GET /runs/{id}/workspace/file?path=…` 只做代理。path 可以为相对路径，或位于任务工作目录内的绝对路径；根来自已存在任务的快照，不接受客户端提供 root。
- 成功返回 `{path, directory, size, modified, version, data}`。data 为不超过 2 MiB 文件的完整字节，version 为这些字节的 SHA-256；普通二进制可读取但 UI 如实显示无法文本预览。超限返回 `{…, too_large:true}`，不假装空文件，也不截取内容后给整文件版本。
- 使用 `os.Root` 约束路径解析，读前以非阻塞方式打开且验证普通文件，避免管道阻塞；不可越界跟随符号链接。不产生任何文件写入，不改变现有模型的“读过才能改”账本。
- 单次读取发现大小或修改时间改变时返回 409，保留旧预览并标过期，可手动刷新。内容版本描述读取到的字节，不承诺未遵守文件锁的外部程序永远不并发改写。
- 旧后端不支持时显示能力不支持/升级提示；不回退到沙箱文件冒充项目文件。网页不在本地直接读服务端路径。

## 验收

用真实 QA 仓库核对普通文本、中文路径、空文件、相对与合法绝对路径、行定位、两文件标签隔离、刷新版本变化、删除、根外路径和 symlink、管道、二进制、超过 2 MiB。浏览器验证点击回答链接、跳行与引用只形成草稿，渲染恶意 HTML 不执行脚本。读文件不增加模型轮次或产生文件变更。每项结果与未覆盖项在 08 留证。

## 截图对齐：目录树与源码层次

用户提供的文件视图采用源码区加其右侧目录树，二者都属于主聊天右侧的工作区。打开文件保留同一个目录树及筛选、展开状态，文件标签切换不跳出右栏；窄右栏可收起树再打开，不能把整页改成独立文件管理器。

- 新增只读 `workspace/tree/list {threadId,path,cursor}`，web `GET /runs/{id}/workspace/tree` 原样代理。path为空表示任务根；仍只从任务快照取根，不接受任意root。非Git目录也可浏览。列表包含真实目录项（含未跟踪/忽略文件），默认不展示 `.git` 内部项；不能用Git搜索的前20个结果冒充完整目录树。
- 每次列一层，目录优先、名称稳定排序，每页200项，返回 `directory/path/entries/version/next_cursor/total`。cursor包含该目录、列表版本和偏移；目录列表变化时旧cursor返回409，界面保留旧内容并要求重新读取，不拼接不同目录版本。单目录超过10000项明确拒绝完整列举并提供搜索/完整路径入口，不返回截断内容冒充完整目录。
- 用受限根目录读取，允许根内链接到目录；根外/损坏链接、设备/管道等不可打开，显示原因。读取期间目录本身被替换/改变返回409。目录版本只描述本次目录项，不是文件内容版本或写锁。
- 树在点展开时懒加载，切任务与迟到结果不能串页。展开/收起、选择文件、刷新、下一页可键盘操作；已加载目录的错误保留旧条目并标明可能过期。筛选复用现有Git可见路径搜索，界面明确最多20个结果及Git限定，清空后回树；完整路径回车仍可直开。
- 源码高亮使用固定版本的本地highlight.js（11.12.0，保留许可证），在Worker里按明确文件语言处理，不运行文件代码，不自动猜语言。把输出解析成受限样式span和文本节点，文件里的HTML/事件属性/脚本不进入可执行DOM。文件超过256KiB、语言不支持、加载失败或Worker超时均继续显示原文和真实行号；高亮不改变用于引用的原始字节/行文本/版本。程序自身带资源，离线不依赖CDN。
